# Sunbeam Group of Educational Institutions — Website Clone

A production-ready, pixel-perfect clone of the **Sunbeam Group of Educational Institutions** website (`https://www.sunbeamschools.com`) built with Next.js 14 (App Router), JavaScript (`.jsx`), Tailwind CSS, and Lucide React.

---

## 🌟 Key Features Implemented

1. **Top Utility Bar**: Direct helpline (+91 9721452435), admissions email, CBSE & Cambridge accreditation badge, and utility links.
2. **Dynamic Multi-Tier Navbar**: Dropdowns for The Group (8 items), Schools (9 campuses), Hostels (4 campuses), Knowledge Partners (16 locations), Colleges (2 campuses), and Philanthropy.
3. **Interactive Hero Carousel**: All 13 slides from reference with autoplay (5s), pause on hover, custom navigation arrows, slide indicators, and slide counters.
4. **Pedagogy Section (4 Pillars)**: IGNITE, THRIVE, REFLECT, and FUTURE-READY with rich interactive cards.
5. **IGNITE Curriculum Section**: 4 developmental academic stages (Foundational Nur-II, Primary III-V, Middle VI-VIII, Senior IX-XII).
6. **THRIVE Parallel Curriculum**: 7 holistic co-curricular pillars (Sports, Leadership, Arts, Outreach, LTA, Excursions, Personality).
7. **REFLECT Section**: Social Emotional Learning (SEL), mindfulness, cultural pride, and zero-tolerance safety frameworks.
8. **FUTURE-READY Section**: Career guidance, student governance, global exchanges, and AI/Robotics labs.
9. **News & Insights**: 9 authentic campus news cards with filterable tags and modal reading previews.
10. **Schools & Colleges Grid**: Interactive tabbed directory covering 9 Flagship Schools, 2 Women's Colleges, and 16 Knowledge Partner cities.
11. **Admission Enquiry Form**: Full validation (names, DOB, 10-digit WhatsApp phone, email format, campus preference, hostel checkbox) and instant confirmation.
12. **Fee Structure**: Clear transparent fee tables and payment rules.
13. **Contact Directory**: Complete contact information for group HQ and all campuses.
14. **ERP Login**: Student, parent, and faculty authentication portal.
15. **Footer**: 4-column layout, 16 Knowledge Partners badges, social media links, and developer credit ("Developed by Rangoli IT Solutions").

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm start
```
